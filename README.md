# DevDesk — AI Developer Workspace

An AI-powered workspace to help developers troubleshoot errors, understand code, and find relevant technical documentation.

> 🚧 **Status:** In development

## Overview

Developers often spend time investigating error messages, searching documentation, and trying different solutions to fix bugs.

DevDesk aims to bring these activities into one workspace by combining an LLM with documentation retrieval to provide structured explanations, suggested fixes, and relevant source references.

## Planned Features

- **Error Analysis:** Explain programming errors in simple language.
- **Code Understanding:** Help developers understand unfamiliar code snippets.
- **Suggested Fixes:** Provide potential solutions and debugging steps.
- **Documentation Search:** Retrieve relevant technical documentation using semantic search.
- **Source References:** Show supporting documentation links when available.
- **Investigation History:** Save previous debugging sessions.
- **Feedback & Evaluation:** Assess answer quality and improve the experience.
